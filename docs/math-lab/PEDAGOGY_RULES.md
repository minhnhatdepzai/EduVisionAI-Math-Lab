# Grade-aware pedagogy rules

| Grade | Primary level | Default approach |
|---|---|---|
| 1-2 | concrete | visible objects, grouping, short steps, reset |
| 3-4 | model | diagrams, fraction/bar models, clock and step reveal |
| 5-6 | model + symbol | connect diagram, unit and formula; bounded value edits |
| 7-9 | dynamic + symbol | connect model, algebra and graph; Why and What If actions |

The deterministic visual rules currently cover arithmetic/counting,
multiplication/grouping, fractions, ratio, time, motion, algebra/functions,
2D/3D geometry, coordinates and measurement. Probability/statistics receive a
registered basic fallback until their dedicated simulation/chart phase.

The planner always reveals: observe data, connect representations, then state
the mathematical relationship. It does not reveal an AI-generated answer.
